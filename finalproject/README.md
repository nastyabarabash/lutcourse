#### Frontend
* React + TypeScript
* React Router
* CSS

#### Backend
* Node.js + Express
* MongoDB
* Mongoose
* JWT (JSON Web Token)

#### Authetication
* Token-based authentication
* Protected routes for authenticated users only

# Installation Guidelines

#### Backend setup
`cd server`<br>
`npm install`

Create .env in server: 

`SECRET=your_secret`<br>
`PORT=5000`

Start backend:<br>
`npm run dev`

#### Frontend setup
`cd client/final`<br>
`npm install`<br>
`npm run dev`<br>
